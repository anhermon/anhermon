# Angel Hermon

I build web products with AI agents, then measure and audit what the agents did.

Featured open source:
- [awesome-agent-observability](https://github.com/anhermon/awesome-agent-observability): curated list of agent observability tools, standards and platforms
- [claude-panel](https://github.com/anhermon/claude-panel): a live panel beside the Claude Code chat, with a board of running subagents
- [awesome-agent-orchestration](https://github.com/anhermon/awesome-agent-orchestration): curated map of agent orchestration and software-factory tools
- [sealref](https://github.com/anhermon/sealref): agents use your secrets without ever seeing them
- [pstack-claude](https://github.com/anhermon/pstack-claude): a port of [poteto's pstack](https://github.com/cursor/plugins/tree/main/pstack) to Claude Code
- [local-harness-router](https://github.com/anhermon/local-harness-router): routes prompts to local harness:model pairs

Shipped with this stack:
- [add-audio-to-video](https://add-audio-to-video.fixmap-site.workers.dev/): add music or a voice-over to a video in your browser, no upload
- [android-16kb-fixmap](https://android-16kb-fixmap.pages.dev/): which Android libraries break Google Play's 16 KB page-size rule, and what fixes them

Sites, case studies and freelance work: [anhermon.dev](https://anhermon.dev)
